Port-Mirroring am RUTX11 einrichten (per SSH als root)

Der RUTX11 hat einen internen Switch-Chip. Mit Mirroring wird der Verkehr eines LAN-Ports zusaetzlich an die Router-CPU kopiert - erst dann sieht der Sniffer auch den direkten Verkehr fremder Geraete an diesem Port.

1. Portbelegung anzeigen (welche Nummer hat welcher LAN-Port?):

swconfig dev switch0 show | grep -i port

2. Mirroring aktivieren - Beispiel: Geraet haengt an Switch-Port 2, Kopie geht an Port 0 (CPU-Port, dort lauscht tcpdump):

swconfig dev switch0 set enable_mirror_rx 1
swconfig dev switch0 set enable_mirror_tx 1
swconfig dev switch0 set mirror_monitor_port 0
swconfig dev switch0 set mirror_source_port 2

3. Nach der Analyse wieder ausschalten (Mirroring kostet CPU/Durchsatz):

swconfig dev switch0 set enable_mirror_rx 0
swconfig dev switch0 set enable_mirror_tx 0
  • Die Einstellung ist NICHT reboot-fest - ein Neustart des Routers loescht sie (gewollt, als Sicherheitsnetz).
  • mirror_monitor_port 0 = CPU-Port; die genaue Nummerierung mit Schritt 1 pruefen (kann je Firmware abweichen - im Zweifel swconfig dev switch0 help).
  • Es kann immer nur EIN Quellport gespiegelt werden - fuer mehrere Geraete den mirror_source_port nacheinander umsetzen und je ein Capture fahren.
  • Voraussetzung fuer den Sniffer: tcpdump installiert (opkg update; opkg install tcpdump) - die Statusanzeige meldet es, falls es fehlt.
