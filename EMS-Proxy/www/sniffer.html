Port-Mirroring - Quellport anklicken, Haken setzen, einschalten. Gruen = Link aktiv. Nicht reboot-fest. Unter jedem Port stehen die dort erkannten Geraete-IPs (aus ARP und Switch-Lerntabelle - ein Geraet erscheint nur, wenn es kuerzlich Verkehr hatte, notfalls einmal anpingen).

Was der Router OHNE Port-Mirroring sieht:
  • ✓ Verkehr von/zu den eigenen Diensten des Routers (Proxy, Geraete-Poller)
  • ✓ Verkehr, der ueber den Router geroutet wird (z.B. Geraet → Internet/Cloud via NAT)
  • ✓ Verkehr von WLAN-Geraeten (SwPort "WLAN?") - der laeuft immer durch die CPU
  • ✗ LAN-zu-LAN-Verkehr FREMDER Geraete (z.B. Tesvolt EMS → Wechselrichter direkt): der Switch-Chip leitet solche Pakete direkt weiter, die Router-CPU (und damit tcpdump) sieht davon NICHTS.
Fuer die volle Sicht auf den Bus-Verkehr das Port-Mirroring oben einschalten (Kopie geht an den CPU-Port 0, dort lauscht tcpdump) - und nach der Analyse wieder AUSSCHALTEN, es kostet CPU und Durchsatz.
Fallback: Port-Mirroring manuell per SSH (als root)

Falls die Buttons oben nicht reagieren (Watchdog aelter als dieser Stand oder gestoppt), funktioniert der Weg ueber die Kommandozeile immer:

1. Portbelegung anzeigen (welche Nummer hat welcher LAN-Port?):

swconfig dev switch0 show | grep -i port

2. Mirroring aktivieren - Beispiel: Geraet haengt an Switch-Port 2, Kopie geht an Port 0 (CPU-Port, dort lauscht tcpdump):

swconfig dev switch0 set enable_mirror_rx 1
swconfig dev switch0 set enable_mirror_tx 1
swconfig dev switch0 set mirror_monitor_port 0
swconfig dev switch0 set mirror_source_port 2
swconfig dev switch0 set apply 1

3. Nach der Analyse wieder ausschalten (Mirroring kostet CPU/Durchsatz):

swconfig dev switch0 set enable_mirror_rx 0
swconfig dev switch0 set enable_mirror_tx 0
swconfig dev switch0 set apply 1
  • Die Einstellung ist NICHT reboot-fest - ein Neustart des Routers loescht sie (gewollt, als Sicherheitsnetz).
  • mirror_monitor_port 0 = CPU-Port; erkennbar an: tagged (0t) in der LAN-VLAN, Mitglied in ALLEN VLANs, 1G-Link ohne "auto" (feste interne Anbindung).
  • Es kann immer nur EIN Quellport gespiegelt werden - fuer mehrere Geraete den mirror_source_port nacheinander umsetzen und je ein Capture fahren.
  • Voraussetzung fuer den Sniffer: tcpdump installiert (opkg update; opkg install tcpdump) - die Statusanzeige meldet es, falls es fehlt.
